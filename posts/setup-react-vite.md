## Pourquoi Vite ?

Vite offre un démarrage instantané et un HMR ultra rapide.

### Installation

    npm create vite@latest mon-projet -- --template react

### Les dépendances utiles

- `react-router-dom` pour le routing
- `gsap` pour les animations
- `split-type` pour le split de texte

## Conclusion

Un setup léger et rapide pour prototyper rapidement.
